# 🍽️ Mimi’s Café – POS Terminal  
### Cyber Range Entry Point | Learn • Study • Play

## Overview

The **POS Terminal** is the starting point of the Mimi’s Café Cyber Range.  
It simulates a real-world retail workstation while serving as a structured learning hub for automation, security analysis, and CTF practice.

This is where the student begins.

---

## Purpose

The POS system represents a realistic corporate endpoint:

- Financially critical  
- Network-connected  
- Frequently targeted  

In this range, it becomes a controlled training environment for both defensive and offensive skill development.

---

## What Students Can Do Here

- Use **VBA tools** for business automation exercises  
- Run **PowerShell scripts** for file discovery, hashing, and logging  
- Interact with lightweight **HTML dashboards**  
- Investigate workstation activity  
- Access a hosted **CTF virtual machine**  
- Practice pivoting from user endpoint to lab attack environment  

---

## Core Components

### 📊 VBA Tools
- Sales tracking macros  
- Reporting automation  
- File export workflows  

### 💻 PowerShell Utilities
- File collection by date range  
- SHA256 hashing  
- Zip archive creation  
- Workstation audit scripts  

### 📈 Dashboards
- Interactive HTML interfaces  
- Student challenge navigation  
- Tool launch panels  

### 🎮 CTF Access
Students can connect to a hosted VM to:
- Practice exploitation in a controlled lab  
- Analyze misconfigurations  
- Correlate offensive actions with defensive logs  

---

## Learning Focus

- Endpoint security fundamentals  
- Automation and scripting  
- File integrity validation  
- Attack surface awareness  
- Defensive visibility  

---

## Why Start Here?

Most real-world breaches begin at the workstation — not the server.

The POS Terminal teaches students how business systems operate, how they are abused, and how they are defended.

This is the entry point to the Mimi’s Café Cyber Range.
