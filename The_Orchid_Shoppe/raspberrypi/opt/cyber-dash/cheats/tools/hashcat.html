🔑 Hashcat Cheats

🎯 Basic Syntax (Linux/macOS CLI)

# Dictionary attack (MD5)
hashcat -m 0 -a 0 hashes.txt rockyou.txt

# NTLM hashes (Windows)
hashcat -m 1000 -a 0 ntlm.txt rockyou.txt

# WPA/WPA2 handshake
hashcat -m 22000 -a 0 handshake.hc22000 rockyou.txt

# Rule-based attack
hashcat -m 0 -a 0 -r rules/best64.rule hashes.txt rockyou.txt

# Brute-force mask attack
hashcat -m 0 -a 3 hashes.txt ?l?l?l?l?l?l

# Restore session
hashcat --restore

# Benchmark supported algorithms
hashcat -b

🪟 PowerShell Usage (Windows)

# Basic use in PowerShell (from hashcat folder)
.\hashcat.exe -m 0 -a 0 .\hashes.txt .\rockyou.txt

# NTLM example
.\hashcat.exe -m 1000 -a 0 .\ntlm.txt .\rockyou.txt

# WPA example (converted .hccapx or .hc22000)
.\hashcat.exe -m 22000 -a 0 .\handshake.hc22000 .\rockyou.txt

# Rule attack (ensure rule file exists)
.\hashcat.exe -m 0 -a 0 -r .\rules\best64.rule .\hashes.txt .\rockyou.txt
